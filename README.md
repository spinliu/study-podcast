# study-podcast

把一篇**难读的专业论文/文档**，变成一段**深入浅出、双人对话**的中文学习播客（MP3）+ 逐字稿飞书文档 —— 用来提升认知带宽。

> 内核是**解读质量**，不是音频。音频只是包装。

## 它做什么

输入一篇硬核内容（飞书文档 / 论文 / 报告），输出：
- 🎧 一段双人对话播客 MP3（女主持提问 × 男专家讲透）
- 📄 一份逐字稿飞书文档

两种模式：
- **精炼版**：~2000 字、一条主线、≤10 分钟
- **详细版**：逐个概念讲透 + 每个名词用比喻记住 + 举一反三，时长跟干货走

## 流水线

```
源文档 ──[输入适配器]──► 纯文本 ──[脚本生成·5标准]──► 双人对话脚本(md)
        ──[CosyVoice TTS]──► 分段配音 ──[ffmpeg]──► MP3
        ──[飞书 import]──► 逐字稿文档 ──► 发回用户
```

## 输入适配层（可扩展）

内核与输入模态解耦，适配器只负责"取文本"：

| 模态 | 状态 |
|---|---|
| 飞书文档 / wiki | ✅ 已实现 |
| PDF / ePub / PPT / 网页 | 🔲 预留接口（见 `references/source-adapters.md`） |

加新模态 = 加一个适配器，内核不动。

## 解读的 5 条质量标准

1. 问题驱动，不是结构驱动
2. 一个主锚比喻贯穿全篇
3. 带判断地读（标出"作者吹的"vs"站得住的"、代理指标陷阱）
4. 放大反直觉的那一下
5. 落到"对你意味着什么"（可迁移的一招）

详见 `references/script-method.md`。

## 为什么比 NotebookLM 更适合"深度学习"

- **可定制**：脚本完全按你的语言、聚焦点、深度来；不满意改了重生成（NotebookLM 是黑盒）
- **带判断地读**：会标出哪些是作者自夸、哪些是代理指标 —— 它没有你的判断坐标系
- **中文母语级**：本土化举例、术语处理更贴
- **进你的系统**：产物直接落飞书、可沉淀进知识库、可批量
- **逐字稿可编辑**：是可复用的资产，不是听完即逝
- **数据不出境**

> 诚实说明：纯音频的"真人随口聊"自然度，NotebookLM 端到端音频模型目前更强。本 skill 用 CosyVoice，自然度够用；可选接 MiniMax/火山进一步提升。

## 依赖

- 阿里云百炼 DashScope（`DASHSCOPE_API_KEY`）：`pip install dashscope --break-system-packages`
- `ffmpeg`
- 飞书开放平台（`FEISHU_APP_ID/SECRET` 建文档；`FEISHU_USER_ACCESS_TOKEN` 读文档）

## 用法

见 `SKILL.md`。核心三个脚本：
- `scripts/fetch_feishu.mjs` — 取飞书文档文本
- `scripts/synthesize.py` — 脚本 → MP3
- `scripts/feishu_doc.mjs` — Markdown → 飞书逐字稿文档
